# Görüntü İşleme - Ödev 1: Görüntü Yeniden Boyutlandırma (1024x768)

Bu projede bir klasördeki (`odev_resimler`) tüm görselleri C++ `std::filesystem` ve OpenCV kütüphanesi kullanılarak okunmuş ve görseller  **1024x768** çözünürlüğünde yeniden boyutlandırılarak `islenen_resimler` klasörüne kaydedilmiştir.

Kullandığım kütüphaneler 
* C++ (std::filesystem)
* OpenCV 4.x (`cv::imread`, `cv::resize`, `cv::imwrite`)
